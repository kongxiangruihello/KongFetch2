# KongFetch 4

macOS 菜单栏工具：像 Spotlight 一样随时唤起，查找并打开文件、文件夹和应用；附带剪贴板历史。
需要 macOS 13 或更高版本。这是对 KongFetch 3.x 的重写，设置和数据与旧版互不影响。

## 安装

1. （只需一次）在“钥匙串访问”中选择“证书助理 › 创建证书…”：名称填 `KongFetch Local Signing`，
   身份类型选“自签名根证书”，证书类型选“代码签名”。有了它，以后每次更新都不必重新授权。
2. 双击 `构建并安装.command`。它会编译、签名，把应用装进“应用程序”并启动。
   如果“应用程序”里是 KongFetch 3.x，会先改名为“KongFetch 3 (旧版).app”保留。
3. 首次启动会打开设置：按提示授予“输入监控”（连按 Control 需要）和“辅助功能”（自动粘贴需要）。

## 使用

| 操作 | 默认按键 |
| --- | --- |
| 打开搜索 | ⌃⌥F，或连按两次 Control |
| 打开剪贴板历史 | ⌃⌥V |
| 切换按名称 / 按内容（全文）搜索 | ⇥ Tab |
| 打开所选 / 在访达中显示 | ↩ / ⌘↩ |
| 快速查看 | ⌘Y |
| 拷贝文件 / 拷贝路径 | ⌘C / ⌥⌘C |
| 直接打开第 N 个结果 | ⌘1 … ⌘9 |
| 粘贴所选历史 / 只粘贴纯文本 / 仅拷贝 | ↩ / ⇧↩ / ⌘↩ |
| 固定 / 删除历史 | ⌘P / ⌘⌫ |

搜索语法：`合同 2024`（同时包含），`"年度 合同"`（短语），`-草稿`（排除），`ext:pdf,docx` 或 `.pdf`，
`kind:folder`（应用、文件夹、图片、pdf、文档、视频、音频、压缩包），`days:7`。
所有含中文的文件名都支持拼音全拼与首字母（如 `lyyz` → 论语译注）：KongFetch 为文稿、桌面、下载、iCloud 云盘
（以及设置中添加的文件夹）维护一个只含中文文件名的本地索引，文件变化后自动更新。

全文模式（Tab 切换）使用 Spotlight 的内容索引，可搜 PDF、Word、Pages、文本等文件正文；右侧预览显示命中处的上下文，PDF 标出页码。

## 结构

```
Sources/KongFetchCore   纯逻辑（有单元测试）：查询语法、排序与拼音、连按识别、剪贴板存储与历史
Sources/KongFetch       应用：悬浮面板、Spotlight 搜索、热键、键盘监听、剪贴板读写、设置
Tests/                  XCTest
scripts/build-app.sh    命令行构建；--test 先跑测试，--install 安装
```

开发时可用 Xcode 直接打开 `Package.swift`：运行 KongFetch 方案，或 ⌘U 运行测试。

## 与 3.x 相比

- 面板不再抢占焦点：唤起时原应用保持在前台，粘贴可以直接落到原处；修正了连按 Control 后窗口出现但无法输入的问题。
- 连按识别改用系统运行时钟，不再依赖事件时间戳；权限缺失时每 3 秒自动重试，授权后无需重启；设置里有逐项诊断。
- 剪贴板：图片单独存文件，索引只存文字；同时有文字和图片时优先记录文字；超大图片自动缩小而不是丢弃；
  保留 RTF 格式并支持纯文本粘贴；索引损坏时另存而不覆盖，单条损坏不影响其他记录；目录不参与时间机器备份；
  优先读取 `org.nspasteboard.source` 判断来源应用。
- 暂未移植：压缩包内搜索、批量重命名、重复文件查找。

## 4.1

- 全部文件的拼音搜索（本地中文文件名索引，FSEvents 增量更新）。
- 全文搜索模式（Tab 切换），按 Spotlight 相关度排序，预览区显示命中上下文与 PDF 页码。

## 4.2

- 扫描件文字识别（OCR）：在设置里选择文件夹，KongFetch 在后台用本机 Apple Vision 识别其中的扫描版 PDF 和图片
  （简体、繁体、英文），之后全文模式能搜到，预览显示页码并标明"识别文字"。默认只在接通电源时进行，
  每个 PDF 默认最多识别 200 页；带文字层的 PDF 交给 Spotlight，iCloud 中未下载的文件不会被强制下载。
- 剪贴板图片识别：复制截图或图片后自动识别其中文字，可搜索；⇧↩ 粘贴识别出的文字，⌘T 拷贝。

## 4.3

- 应用内更新：KongFetch 每 6 小时（及启动时）检查 GitHub 上的新提交，菜单栏出现"安装更新"。
  更新在本机进行：拉取代码、编译、用同一证书签名；新版本签名与当前版本不一致时拒绝安装，
  因此输入监控、辅助功能等权限保持不变。安装前自动备份当前版本，设置"更新"页可一键回退；日志在
  `~/Library/Application Support/KongFetch4/update.log`。源码文件夹有未提交的修改时不会更新。
- 回退后，“检查更新”以本机实际安装的版本为准，会重新提示可更新到最新版（4.3.2 起）；
  回退列表不再显示正在运行的版本本身（4.3.3）。

## 4.4

- 剪贴板文本整理：在剪贴板窗口选中一条，按 ⌘J 整理后粘贴（纯文本）；⌘E 预览整理效果；⌘K 打开操作菜单，可单项整理或调整整理方式。
  - 去除多余换行：合并排版造成的断行，修复英文断词（compre-/hensive）；空行、首行缩进、编号列表、句末短行视为分段。
  - 中文标点改为全角：只改紧挨汉字的 , . ; : ? ! ( ) "，数字、网址、英文句子不动；"..." 改为"……"。
  - 清理多余空格：去掉汉字之间、中文标点两侧的空格，去掉零宽字符，合并连续空格和空行。
  - 繁简转换：使用 macOS 内置的 ICU 转换，按字对应，转换后请校对。
  - 图片条目对识别出的文字同样适用。默认组合在 设置 › 剪贴板 中修改。
- 网页搜索：在搜索窗口输入"关键词 + 空格 + 内容"，例如 `hd 仁`（汉典）、`ct 学而`（中国哲学书电子化计划）、`zw 王阳明`（知网）、`db`（豆瓣读书）、`gs`（Google 学术）、`wk`（维基百科）、`bk`（百度百科）、`g`、`bd`。找不到文件时，列出标为"兜底"的网站。设置 › 网页搜索 可增删改。

## 4.5

- 文本片段：常用文字（落款、课程信息、引文格式……）保存为片段。
  - 在剪贴板窗口按 ⇥ 切换到"片段"，搜索名称、关键词或内容，↩ 粘贴。
  - 给片段设关键词（如 `;lk`），在任何应用中输入关键词即自动替换。需要"输入监控"和"辅助功能"权限。ABC 键盘下直接展开；使用拼音等输入法时，先通过辅助功能确认关键词确实已输入（英文状态下输入即可，中文状态下 `;` 变成 `；` 不会误触发）。密码管理器中不展开；替换后原剪贴板内容会放回。
  - 占位符：`{日期}`（2026年10月8日）、`{date}`、`{time}`、`{weekday}`、`{clipboard}`、`{cursor}`（展开后光标停在此处）。
  - 在 设置 › 片段 中编辑；数据保存在 `~/Library/Application Support/KongFetch4/snippets.json`。

## 4.6

- 查词：在任何应用中选中字词，按 ⌃⌥D（可在设置 › 通用 中修改），在搜索窗口显示系统词典的释义；也可以直接输入 `cd 仁`。↩ 在"词典"App 中打开，⌘C 拷贝释义；系统词典没有时可一键转到汉典。用的是"词典"App 中已启用的词典（可在其设置中勾选现代汉语、牛津英汉汉英等）。
- 搜索结果操作菜单（⌘K）：打开方式、在访达中显示、快速查看、拷贝文件/路径/名称、在终端中打开、移到废纸篓（可从废纸篓放回）。
- 文件夹限定：`in:论文 王阳明` 只看名称含"论文"的文件夹里的结果；`in:~/Documents/讲义 学而` 只在该路径中搜索。
- 拖出：搜索结果可直接拖到微信、邮件、访达等处。

## 4.7

- 备份与迁移：设置 › 通用 ›"导出设置…"保存一个 `.kfsettings` 文件（全部设置、网页搜索、片段；不含剪贴板历史），在另一台 Mac 上"导入设置…"即可恢复，KongFetch 会自动重新打开。
- 诊断包：设置 › 诊断 ›"导出诊断包…"生成一个 zip（状态报告、更新与编译日志、最近的崩溃报告、设置），不含剪贴板内容、片段正文和最近打开的文件。

## 4.8

- 与 KongReview 联动（通过 `kongreview://add` 链接，只打开快速录入浮窗并填好内容，确认后才保存）：
  - 剪贴板窗口选中一条，⌘R（或 ⌘K ›"送到 KongReview 摘录"）；打开了整理预览时送整理后的文字。
  - 任何应用中选中文字，按"摘录所选文字到 KongReview"快捷键（设置 › 通用 中设定，默认不设）或从菜单栏图标选择；窗口标题是 PDF、EPUB、Word 等文档名时作为出处带上。
  - 搜索窗口输入 `kr 学而时习之`。网页搜索列表新增 `kr`，已有的列表会自动补上。
- KongVox 目前没有对外的链接或"服务"入口，暂未联动。

## 4.9

- 批量重命名（菜单栏图标 ›"批量重命名…"，或搜索结果 ⌘K ›"批量重命名…"）：
  - 加入文件：拖进窗口、"添加文件…"，或"使用访达中选中的文件"（第一次会请求控制"访达"的权限）。
  - 查找替换（可用正则表达式，`$1` 引用分组），或按模板编号：`{name}` 原名、`{n}` 编号（可设起始和位数）、`{date}` 修改日期、`{parent}` 所在文件夹；编号可按列表、名称或修改时间排序。可同时繁简转换，默认保留扩展名。
  - 改名前逐个预览，重名、非法字符、与已有文件冲突都会标出并跳过；名称互换也能正确处理（先改成临时名）。任何一步失败会全部恢复；改完可"撤销"。记录在 `~/Library/Application Support/KongFetch4/rename.log`。
